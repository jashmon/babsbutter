# Babs Butter

The Babs Butter marketing site, built with Astro. See `CLAUDE.md` for brand, asset, and architecture reference.

## Running the site

```sh
cd site
npm install
npm run dev
```

Dev server runs at `http://localhost:4321/`.

Other commands (run from `site/`):

| Command | Action |
| --- | --- |
| `npm run dev` | Start local dev server |
| `npm run build` | Build production site to `site/dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run astro ...` | Run Astro CLI commands (e.g. `astro check`) |

Requires Node `>=22.12.0` (see `site/package.json`).
